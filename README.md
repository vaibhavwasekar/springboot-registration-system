# Spring Boot User Registration & Login System

A complete user registration and login system built with Spring Boot, Thymeleaf, and MySQL.

## 📋 Features
- ✅ User Registration with form validation
- ✅ Secure User Login authentication
- ✅ Profile Dashboard after successful login
- ✅ Session Management with logout functionality
- ✅ Responsive HTML pages using Thymeleaf templates
- ✅ MySQL Database integration with Spring Data JPA
- ✅ Error handling with custom error pages

## 🛠️ Technologies Used
- **Backend Framework**: Spring Boot 3.x
- **Frontend**: Thymeleaf, HTML5, CSS
- **Database**: MySQL 8.0+
- **ORM**: Spring Data JPA / Hibernate
- **Build Tool**: Maven
- **Java Version**: 17+
- **Server**: Embedded Tomcat
